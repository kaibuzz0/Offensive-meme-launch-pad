Six existing beta mints are the first character identities. We are building an original browser world in stages. There are no new game contracts, token purchases, promised earnings, or paid founder access in this release.

01 / LIVE ALPHA 02

The first neighborhood

Explore a neon city with ambient traffic and pedestrians. Fight hostile bots, evade police patrols, dash, collect health and credits, and run repeatable combat, delivery, and pursuit contracts. Choose a beta-token avatar, upgrade gear, and save solo progress on this browser. Keyboard and two-thumb mobile controls work.

02 / CODE READY
HOSTING PENDING

Meet in a shared city

A room server is included in the repository: up to 32 temporary guest sessions, shared movement, chat, authoritative mission rewards and inventory, and player listings traded for play credits. This GitHub Pages deployment is solo; no public online room is connected.

Release gate: host the HTTPS room service, test multiple real devices, add durable player accounts, moderation, abuse controls, operational monitoring, and recovery. Temporary room state currently resets on server restart.

03 / PLANNED

Wallet identity & holding tiers

Connect a wallet, prove control with a scoped sign-in message, and verify balances server-side against the six allowlisted Solana mints. Publish each token’s supply-normalized tier rules, a maximum starting boost, snapshot timing, and what happens after selling.

Separate earned XP from holding perks. Never trust a balance supplied by a browser. No holder tier or token balance is verified in the current game.

04 / PLANNED

A marketplace worth using

Turn temporary room trading into durable item ownership with transaction history, atomic escrow, reconnect recovery, fraud checks, and support tools. Keep play credits separate from real assets.

Any future SOL or token marketplace needs a separately reviewed settlement design and explicit wallet approval. No game item is currently an NFT, redeemable asset, or source of cash rewards.

05 / PLANNED

Creators bring their worlds

Creator profiles, moderated artwork uploads, preset avatar bodies, emotes, and community spaces. Start with token artwork on a shared character model; later add reviewed custom 3D mascots and animations.

Prelaunch spaces let people discover a meme and meet its community before token creation. Launch approval and audit evidence remain separate from artwork approval.

06 / PLANNED

More city. More chaos.

Drivable vehicles, cooperative missions, events, richer animation, and additional neighborhoods. The current build has arcade combat against enemy bots and cops, health and respawning. Traffic is ambient scenery; vehicles are not yet drivable. Player-versus-player damage remains disabled.

Expand after performance, mobile controls, server capacity, moderation, and saving are dependable. No release dates are promised.
