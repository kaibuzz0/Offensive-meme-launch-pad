# Coin artwork

Created with the built-in image-generation tool. The 10 final site assets are 1254 × 1254 pixel WebP images in `assets/coins/`; the original SVG posters remain unchanged as backups. Full-resolution PNG generation outputs were also shown in the conversation.

## Shared generation prompt

Use case: stylized-concept. Create ONE finished square 1:1 meme-token icon for the OFFENSIVE Solana collection, not a grid, not a sheet, not a physical coin photo. Professional outrageous editorial cartoon / underground sticker art: thick dark contour lines, exaggerated expressive character, clean saturated color blocks with tactile halftone and screenprint texture, high contrast, bold simple silhouette legible at 64 pixels. Large centered subject with all important features within central 80% for circular cropping, full-bleed opaque background, graphic circular framing. Cohesive premium meme-coin art, funny, profane, sharp and irreverent. Include only the requested slogan, large and correctly spelled in a compact curved or stacked headline integrated with the illustration, no small text, no ticker, no extra logos, no watermark. This is obvious fictional caricature and satire, not documentary photography.
